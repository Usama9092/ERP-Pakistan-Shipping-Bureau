# EPAS v2.7

Cumulative final workflow-enforcement release for the Streamlit + Supabase EPAS platform.

## Start locally

```bash
./run_streamlit.sh
```

or:

```bash
python -m streamlit run app.py
```

## Included

- Role-authenticated Streamlit application.
- Persistent In-Service survey lifecycle.
- Controlled NSC and In-Service RFI initiation.
- Immutable approved drawing handover.
- Package fingerprint acknowledgement.
- Versioned scope/checklist/execution basis.
- Server-side survey start/report gates.
- Explicit recurring survey schedule basis.
- Service-role scheduler.
- Project-scoped security wrappers.
- P0/P1 workflow acceptance matrix.
- Deployment runbook and Dockerfile.
