# EPAS v4.0 Project-Centric Frontend Preview

Open `epas_v4_project_specific_role_preview.html` in a browser.

The preview demonstrates the selected-project experience for all roles using the same PSB shell and project navigation. It intentionally excludes Workflow Snapshot and Recent Activity from the Project Overview.

Project navigation:
Project Overview → Plan Appraisal* → NSC Survey* → In-Service Survey* → Survey Status → Risk Register → Ship Register → Certification → Documents → Notifications → Audit Trail

*Phase navigation appears only when the phase is included in the project scope.

Only GM has the Create Project action, and it is exposed from the Projects register in the active Streamlit application.
