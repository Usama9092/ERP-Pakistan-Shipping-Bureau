# EPAS v4.1.3 — Fixed Navigation + Sign-out

## Navigation

- The global role navigation is vertical inside a fixed left sidebar.
- The sidebar is vertically scrollable when needed and prevents horizontal overflow.
- Once a project is selected, global navigation disappears and the project-specific navigation replaces it.
- The project sidebar contains only navigation controls and does not show project code, vessel, project summary, current cycle or other project information.
- Project-specific phase entries appear only when included in the selected project scope.
- Change Project is available near the bottom of the project navigation.
- Sign out is always the final navigation action.

## Project navigation

Project Overview → Plan Appraisal (if included) → NSC Survey (if included) → In-Service Survey (if included) → Survey Status → Risk Register → Ship Register → Certification → Documents → Notifications → Audit Trail.
